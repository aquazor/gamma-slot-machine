What You'll Need

  • S.T.A.L.K.E.R.: GAMMA installed and working
  • The GAMMA Slot Machine.exe app — it installs the mod itself, no separate MO2 setup needed
  • A Twitch account for the streamer
  • OBS (or another broadcast software with a Browser Source)

Part 1 — Run The App

Launch GAMMA Slot Machine.exe. The Settings page opens automatically in your browser, and the app keeps running locally at localhost:7770 for as long as you want the roulette to react to Twitch.

Its console confirms it found your GAMMA and Anomaly folders, and that Twitch isn't connected yet.

If it says NOT FOUND instead, that's fine — you can set both folders by hand from Settings → Mod install (step 9 below).

Part 2 — Connect Twitch

  1. On the Settings page, click Connect Twitch.

  2. A code appears in the app and a Twitch activation page opens in your browser. Enter it and click Activate.

  3. Twitch asks you to confirm access for the app — click Authorize.

  4. Back in Settings, wait a moment and check that Twitch shows Connected and Listening, then copy the Browser Source URL — you'll need it in the next part.

Part 3 — Add The Overlay To OBS

  1. In OBS, click + under Sources, choose Browser, then Add a new Browser.

  2. Paste the overlay URL you copied, set Width to 1200 and Height to 600, then click OK.

Back in Settings, the OBS overlay row should now show Connected too — if not, try re-adding the source.

Part 4 — Install The Mod

The app's console should also confirm your channel-point rewards loaded and Twitch EventSub is connected and subscribed.

  1. Open the Mod install section and click Install — this copies the mod straight into your Anomaly folder, so it works whether you launch through the GAMMA launcher or the game exe directly.

    If GAMMA/Anomaly weren't found automatically, click Set manually… and pick them yourself first.

Part 5 — Turn On Rewards

  1. Open Channel point rewards and click Enable rewards. Tick Auto-activate on startup/connect too if you want them to turn back on by themselves next time you open the app.

  2. (Optional, recommended) Set up Bits power-ups too, following the linked step-by-step guide.

Part 6 — You're Live

Once everything above is set, try any of these events and watch the roulette play out in OBS.

Subs, resubs, gift subs, channel-point redemptions and bits power-ups will now trigger the roulette live on stream.
